# 🔍 AutoComplete Search

A modern AutoComplete Search component built with **React**, **TypeScript**, and **Vite** that demonstrates common frontend interview concepts such as debouncing, caching, keyboard navigation, and efficient state management.

## ✨ Features

- 🔎 Real-time search suggestions
- ⏱️ Debounced API requests
- 💾 Client-side caching
- ⌨️ Keyboard navigation (Arrow Up / Down)
- ⏎ Enter key selection
- 🖱️ Mouse selection support
- 🚫 Handles empty search queries
- 📱 Responsive UI
- ⚡ Fast rendering with optimized state updates

## 🛠️ Tech Stack

- React 19
- TypeScript
- Vite
- CSS
